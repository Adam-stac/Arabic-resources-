
# Arabic Curriculum Comparative Research

## Project Overview

An exhaustive, source-grounded comparative study of three Arabic language-learning curricula.

The project investigates their linguistic content, teaching methodology, vocabulary, grammar progression, reading materials, stories and exercises.

## Research Requirements

Analyse every lesson, passage, story, dialogue and exercise.

Extract and catalogue:

- Vocabulary, roots, meanings and word patterns.
- Verbs, conjugations and maṣdars.
- Naḥw and ṣarf concepts.
- Sentence structures and linguistic progression.
- Reading difficulty and assumed prerequisites.
- Teaching methods and exercise types.
- Stories, characters, events and themes.

## Comparative Analysis

Compare all three collections for:

- Shared and differing vocabulary.
- Grammar and morphology progression.
- Teaching approaches.
- Reading complexity.
- Storytelling and narrative development.
- Strengths, weaknesses and omissions.

## Evidence Standards

Every finding must be traceable to:

- Source collection.
- Book and level.
- Lesson or chapter.
- Original PDF page.
- Relevant Arabic text.

Distinguish explicit source evidence from analytical interpretation.

Never invent missing material.

## Deliverables

- Individual book reports.
- Comparative curriculum reports.
- Story catalogue.
- Vocabulary database.
- Naḥw and ṣarf database.
- Exercise inventory.
- Searchable SQLite database.
- CSV, Markdown and PDF reports.

## Processing Requirements

- Process in small, verifiable batches.
- Preserve Arabic text and tashkīl.
- Validate OCR accuracy.
- Record page-level progress.
- Save results incrementally.
- Support interruption and resumption.
- Track API usage and costs.
- Prevent duplicate processing.

## Repository Principles

- Keep the repository private.
- Store original PDFs using Git LFS.
- Never commit API keys or credentials.
- Keep source documents separate from extracted research.
- Maintain reproducible processing scripts.
